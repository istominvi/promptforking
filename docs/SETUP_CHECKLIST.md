# Promptforking — чеклист настройки инфраструктуры

Это шаги, которые нужно сделать **руками** в браузере и терминале до того, как Claude Code начнёт писать код. Цель: к концу этого чеклиста у тебя есть пустой GitHub-репозиторий, подключённый к Vercel, и Supabase-проект с пустой БД. После этого запускается промпт `prompts/01-bootstrap.md`.

---

## Принятые решения для MVP

Фиксируем, чтобы не плавать:

1. **Стек:** Next.js 15 (App Router) + TypeScript + Tailwind v4, Supabase (Postgres + Auth), Cloudflare R2 для медиа (подключаем не на первом шаге), Vercel для деплоя, GitHub для кода.
2. **Менеджер пакетов:** `pnpm`.
3. **Провайдеры генерации:** Replicate + fal.ai. Только BYO-API-key — пользователи приносят свои ключи, мы не платим за инференс.
4. **Формат шаблонов:** промпт + JSON-описание полей. Плейсхолдеры в промпте — `{{name}}`. Типы полей в MVP: `text`, `textarea`, `select`, `image`.
5. **Форк-семантика:** дерево привязано к модели. Копируется промпт + параметры. Смена модели = новый корень.
6. **Шаблоны:** immutable. Обновление = новая версия рядом, старая остаётся жить.
7. **Публичность:** всё public по умолчанию. Private появится как платная фича позже.
8. **Контент:** SFW only на старте. В БД сразу закладываем поле `content_rating` под будущее расширение.
9. **Медиа на старте:** сохраняем URL картинки от провайдера. Свой R2 подключаем во втором или третьем спринте.

## Шаг 1. Купить домен

Купи `promptforking.com` (или другое имя, если занято) на Namecheap, Porkbun или Reg.ru. ~$3–15/год. DNS пока никуда не указывай — настроим, когда Vercel выдаст IP/CNAME.

## Шаг 2. GitHub-репозиторий

1. Создай новый репозиторий `promptforking` на GitHub. **Private** на старте.
2. **Не** инициализируй с README/`.gitignore` — пусть будет совсем пустой. Claude Code положит туда первый коммит.
3. Скопируй URL вида `git@github.com:<твой-юзер>/promptforking.git` — он понадобится.

## Шаг 3. Supabase-проект

1. Зайди на [supabase.com](https://supabase.com), создай новый проект:
   - Name: `promptforking`
   - Database password: сгенерируй случайный, **сохрани в менеджере паролей**.
   - Region: ближайший (EU Central / West для России, US East для глобального трафика).
   - Plan: Free.
2. После создания (ждать 1–2 минуты) зайди в `Project Settings → API`. Скопируй и сохрани:
   - `Project URL` (вида `https://xxx.supabase.co`)
   - `anon public` key
   - `service_role` key (это секрет, нигде не показывай)
3. Включи **Email auth** в `Authentication → Providers`. Magic links можно оставить по умолчанию.
4. Дальше схему БД не трогай — Claude Code применит миграции через MCP.

## Шаг 4. Vercel

1. Зайди на [vercel.com](https://vercel.com), залогинься через GitHub.
2. **Пока не импортируй репозиторий** — он пустой. Сделаешь это после первого коммита от Claude Code.

## Шаг 5. Локальное окружение

Установи на свою машину, если ещё нет:

- **Node.js 20+** (через `nvm` или `volta`).
- **pnpm** (`npm install -g pnpm`).
- **Git** настроен на GitHub (SSH-ключ добавлен).
- **Claude Code** установлен и работает.
- (Опционально) **Supabase CLI** — `brew install supabase/tap/supabase` — пригодится, если захочешь тянуть схему локально.

## Шаг 6. Аккаунты у провайдеров (только для твоих тестов)

Эти аккаунты нужны тебе как разработчику, чтобы тестировать генерации. Пользователи будут приносить свои ключи.

1. [replicate.com](https://replicate.com) → зарегистрируйся → `Account → API tokens` → создай токен.
2. [fal.ai](https://fal.ai) → зарегистрируйся → `Dashboard → API Keys` → создай ключ.

Положи на каждом по $5 для теста. Сохрани оба ключа — они уйдут в `.env.local` для разработки.

## Шаг 7. Cloudflare R2 (отложить)

Пока **не настраиваем**. На первом спринте мы храним только URL картинок от провайдера. R2 подключим, когда:

- появятся пользовательские загрузки референсов (для `type: image` полей),
- или мы решим делать собственные копии генераций для надёжности.

Когда это случится — отдельный промпт.

## Что нужно собрать в один файл перед запуском Claude Code

Открой файл `~/promptforking-secrets.txt` (или любой удобный) и положи туда:

```
GITHUB_REPO_URL=git@github.com:<юзер>/promptforking.git

SUPABASE_URL=https://xxx.supabase.co
SUPABASE_ANON_KEY=eyJhbGciOi...
SUPABASE_SERVICE_ROLE_KEY=eyJhbGciOi...
SUPABASE_DB_PASSWORD=<пароль из шага 3>

REPLICATE_API_TOKEN=r8_...
FAL_API_KEY=...
```

Эти значения Claude Code попросит при запуске промпта `01-bootstrap.md`.

---

## Когда чеклист пройден

Открывай `prompts/01-bootstrap.md` и копируй его содержимое в Claude Code (запущенный в пустой папке, куда планируешь клонировать репо). Дальше следуй инструкциям из промпта.
